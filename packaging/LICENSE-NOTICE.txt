FFmpeg is run as a separate program; Fortnite Visual Chest Counter does not link against it. Where to get the FFmpeg
source code for the bundled build is explained in runtime\ffmpeg\FFMPEG-NOTICE.txt. The Qt libraries are separate,
dynamically loaded files; where to get their source code is explained in runtime\licenses\Qt-NOTICE.txt.

"Fortnite Visual Chest Counter.exe" is a small launcher that is part of this program (MIT): it starts the app with the
bundled Python. Its source code is packaging/launcher/launcher.c in the project's repository.
